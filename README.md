### OFFICIAL LEARNING REPOSITORY FOR THE GENAI TRACK: HONRATECH BOOTCAMP

#### Getting Started
* Create your [fork](https://github.com/mokenyu/hello-world-repo-honratech/fork)
* Clone the repo.
* Create new remote called `upstream` to handle syncing with the forked repo.
```
git remote add upstream https://github.com/mokenyu/hello-world-repo-honratech
```

#### Environment Setup
* After creating clone, cd into it or enter it in your terminal or VSCode IDE.
* Create virtual environment using `uv`.
```
uv venv
```
* Install dependencies and equip environment.
```
uv sync
```
